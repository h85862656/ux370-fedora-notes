# 10. 讓 Chrome 的 LINE 擴充套件像 PWA 一樣獨立顯示在工作列

**狀態**：未開始
**認領視窗**：（尚未認領）

## 目標

讓 Chrome 上的 LINE 擴充套件，能像獨立的 PWA 應用程式一樣，在 GNOME 工作列/應用程式清單裡顯示成一個獨立圖示、獨立視窗，而不是依附在 Chrome 主視窗裡或只是工具列上的一顆小圖示。使用者提到 Chrome OS Flex 上可以做到這件事，想在 Fedora 上比照。

## 背景

Chrome/Chromium 支援把網頁「安裝為應用程式」（PWA，或舊式 Chrome App），安裝後會產生獨立的 `.desktop` 捷徑，讓 GNOME 把它當成一般應用程式對待、有自己的圖示與工作列項目，背後原理通常是用 `chrome --app=<url>` 這種模式獨立開視窗。要研究的重點：

- 使用者要的是「LINE 的**擴充套件**」——這裡要先澄清一個常見誤解（連 AI 一開始也常講錯）：**現在所謂的「網頁版 LINE」其實就是這個 Chrome/Edge 擴充套件本身，並不是另外存在一個獨立的網頁版應用程式**，兩者是同一個東西，所以「擴充套件做不到就改用網頁版 LINE 包成 PWA」這個備案邏輯上不成立，沒有另一條路可退（來源：https://mrmad.com.tw/line-web-discontinued-alternatives）
- **重要時效性**：根據上述來源，LINE 官方已證實這個瀏覽器擴充套件版本預計在 **2026年上半年終止服務**（原訂 2025年9月下架，因視障權益團體反應延後）。開始研究前，先評估這個目標的優先順序是否還有意義——如果官方版本快要停用，可能要考慮這項要不要往後排、或改成等 LINE 官方停用後再看有什麼替代通訊軟體，而不是投入時間解決一個快要消失的擴充套件的顯示問題
- Chrome OS Flex 能做到獨立圖示，代表底層 Chromium 本身具備這個能力，重點是怎麼在標準 Fedora + GNOME 環境下重現同樣效果（可能跟 Chrome OS 特有的 shelf/app list 整合有關，不一定能 1:1 搬過來，需要先查證）
